# 白酒行业上市公司财务对比分析

以贵州茅台（600519）、五粮液（000858）、泸州老窖（000568）为样本，基于 2015—2024 年年报数据，
从**盈利能力、成长性、股东回报**三个维度做横向对比，并用杜邦分解解释 ROE 差异的来源。

## 数据

- 来源：新浪财经公开财报接口（akshare `stock_financial_report_sina`）
- 范围：三家公司利润表与资产负债表，取报告日为每年 12 月 31 日的年报
- 存储：SQLite 数据库 `数据/finance.db`，共 6 张表

## 指标口径

| 指标 | 计算方式 |
|---|---|
| 净利率 | 归母净利润 ÷ 营业总收入 |
| 营收增速 | （本期营收 − 上期营收）÷ 上期营收（`LAG` 窗口函数） |
| ROE | 归母净利润 ÷ 平均归母股东权益（期初与期末均值） |
| 总资产周转率 | 营业总收入 ÷ 总资产 |
| 权益乘数 | 总资产 ÷ 归母股东权益 |

## 核心结论

1. **盈利能力**：2024 年净利率为茅台 49.52%、老窖 43.19%、五粮液 35.72%。九年间老窖提升 21.85
   个百分点，改善幅度最大，2020 年反超五粮液。
2. **成长性**：2017 年茅台营收增速 52.07% 为行业高点，2024 年三家增速降至 15.66%、7.09%、3.19%。
   行业由增量扩张转入存量竞争。
3. **股东回报**：2024 年 ROE 为茅台 38.43%、老窖 30.35%、五粮液 24.24%。杜邦分解显示茅台的
   优势来自"高净利率 + 高周转"，权益乘数仅 1.28、为三家最低，回报质量最高。

> 数据说明：2025 年年报中五粮液营业收入同比下降 54.55%，与同业走势严重背离，判断为数据源异常，
